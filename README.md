# KRISHI RAKSHAK
### AI-Powered Agricultural Intelligence Platform

**Intelligent Crop Monitoring. Early Disease Identification. Smarter Agricultural Decisions.**

Krishi Rakshak is an AI-powered agricultural intelligence platform designed to support farmers in monitoring crop health, identifying potential diseases, and making informed farming decisions.

The platform brings together multiple agricultural factors, including crop images, weather conditions, growth stages, soil information, visible symptoms, and historical observations to provide contextual insights and practical recommendations.

---

## 1. Overview

Agriculture is highly dependent on environmental conditions, crop health, and timely decision-making. However, farmers often face challenges in identifying crop diseases, understanding changing crop conditions, and accessing relevant agricultural guidance.

Krishi Rakshak aims to address these challenges through a simple, accessible, and intelligent digital platform.

The system focuses on transforming agricultural observations into meaningful information that can help farmers make better-informed decisions.

## 2. Problem Statement

Farmers frequently encounter challenges such as:

- Delayed identification of crop diseases.
- Limited access to timely crop health information.
- Difficulty understanding the impact of weather conditions.
- Lack of context-aware agricultural recommendations.
- Challenges in tracking crop conditions across different growth stages.

These challenges can affect crop productivity and increase the risk of agricultural losses.

## 3. Proposed Solution

Krishi Rakshak provides a unified agricultural intelligence platform that considers multiple factors before generating relevant crop insights.

The platform is designed to incorporate:

- Crop images for visual crop health assessment.
- Weather conditions for environmental context.
- Crop growth stages for stage-specific analysis.
- Soil information for agricultural context.
- Symptoms and observations for identifying potential crop issues.
- Historical observations for understanding changes over time.

## 4. Core Features

### Crop Image Analysis
Analyze submitted crop images to help identify visible signs of diseases and crop health issues.

### Disease Identification
Assist in recognizing potential crop diseases based on visual symptoms and relevant crop information.

### Weather-Based Intelligence
Consider weather conditions to provide more context-aware agricultural insights.

### Growth Stage Analysis
Evaluate crop conditions based on the current stage of crop development.

### Soil-Based Insights
Incorporate soil-related information to support agricultural assessment and recommendations.

### Historical Crop Observations
Use previous observations to understand crop condition changes over time.

### Farmer-Friendly Interface
Provide a simple and accessible interface that makes agricultural information easier to understand.

## 6. Project Architecture

The platform is designed around the following workflow:

1. User provides crop-related information.
2. The system receives crop images and agricultural observations.
3. Relevant environmental and growth-stage information is considered.
4. The system processes the available information.
5. Agricultural insights and recommendations are presented to the user.

## 7. Installation and Setup

### Prerequisites

Ensure that the following tools are installed:

- Node.js
- npm
- Git

### Clone the Repository

```bash
git clone https://github.com/Riya-1210/Krishi-Rakshak.git
```

### Navigate to the Project Directory

```bash
cd Krishi-Rakshak
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Open the local development URL displayed in your terminal.
